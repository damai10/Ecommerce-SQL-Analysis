# Ecommerce Sales SQL Analysis

## Project Overview
This project analyzes an ecommerce sales dataset using SQL to generate business insights.

## Tools Used
- SQL
- MySQL Workbench
- GitHub

## Analysis Performed
- Total sales calculation
- Total orders analysis
- Sales by region
- Top products by revenue
- Monthly sales trend
- Category-wise sales
- Top customers by spending

## Key Insights
1. The West region generated the highest total sales.
2. A small number of products contribute most of the revenue.
3. Sales fluctuate across months indicating seasonal demand.
4. Certain customers contribute significantly to total sales.
